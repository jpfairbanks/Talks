Every deck is built from one library of slides, so a slide fixed once is fixed in every talk that uses it. reveal.js, KaTeX and the fonts are served alongside the slides rather than loaded from a CDN, so a deck presents offline and does not break when an upstream version is withdrawn.

In a deck, arrow keys navigate, Esc shows the slide overview, and S opens the speaker view.
